## 4. 物料原料查询接口 `MaterialYLQuery`

- **文件**：`/Technology/MaterialYLQuery.aspx`
- **功能**：获取物料原料信息（工艺 BOM 中的原料明细）
- **请求方式**：GET/POST（表单参数）

### 请求参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| wlname | String | 物料名称 |
| hhname | String | 货号名称 |
| color | String | 颜色 |
| chima | String | 尺码 |
| buj | String | 部件 |
| gys | String | 供应商 |
| guige | String | 规格 |
| pihao | String | 批号 |
| nianx | String | 捻向 |
| dw | String | 单位 |

### 响应结果（数组 `List<MaterialYLQueryOutput>`）

| 字段 | 类型 | 说明 |
|------|------|------|
| hhname | String | 货号名称 |
| color | String | 颜色 |
| chima | String | 尺码 |
| buj | String | 部件 |
| gys | String | 供应商 |
| wlname | String | 物料名称 |
| guige | String | 规格 |
| wlcolor | String | 物料颜色 |
| pihao | String | 批号 |
| nianx | String | 捻向 |
| dw | String | 单位 |
| djyl | Decimal? | 单件用量 |
| sh | Decimal? | 损耗 |
| remark | String | 备注 |
