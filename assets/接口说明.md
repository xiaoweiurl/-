# 接口说明

## 1. 订单列表查询接口 `getOrdeListQuery`

- **文件**：`/OrderPrice/getOrdeListQuery.aspx`
- **功能**：按条件查询订单列表（下单日期范围 + 状态 + 执行状态 + 可选模糊条件）
- **请求方式**：GET/POST

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| dates | DateTime | 是 | 下单开始日期 |
| datee | DateTime | 是 | 下单结束日期 |
| jh_dates | DateTime | 否 | 交货开始日期 |
| jh_datee | DateTime | 否 | 交货结束日期 |
| dh | String | 否 | 单号（模糊） |
| state | String | 是 | 状态，逗号分隔多值：`0`编辑、`1`审核、`3`待审核，如 `0,1,3` |
| recheck | String | 是 | 执行状态，逗号分隔多值：`0`未审核、`1`已复审、`2`已终审，如 `0,1,2` |
| ddtype | String | 否 | 销售类型（模糊） |
| khname | String | 否 | 客户名称（模糊） |
| huohaocp | String | 否 | 成品货号（模糊） |
| huohao | String | 否 | 生产货号（模糊） |
| ywyname | String | 否 | 业务员（模糊） |
| sfplan | String | 否 | 是否下计划（模糊） |
| zhuser | String | 否 | 制单人（模糊） |
| checkuser | String | 否 | 审核人（模糊） |

### 响应结果（数组 `List<OrderListQueryOutput>`）

| 字段 | 类型 | 说明 |
|------|------|------|
| dh | String | 单号 |
| zhdate | DateTime | 下单日期 |
| state | String | 状态文本：`0`→编辑、`1`→审核、其他→待审核 |
| zxtate | String | 执行状态文本：`0`→未审核、`1`→已复审、其他→已终审 |
| printnum | Int32? | 打印次数 |
| jh_date | DateTime? | 交货日期 |
| business_dh | String | 业务单号 |
| ddtype | String | 销售类型 |
| khname | String | 客户名称 |
| detailhuohaocp | String | 成品货号 |
| detailhuohao | String | 生产货号 |
| sl_sum | Decimal? | 数量合计 |
| remark | String | 备注 |
| ywyname | String | 业务员 |
| sfplan | String | 是否下计划 |
| zhuser | String | 制单人 |
| checkuser | String | 审核人 |
| ckeckdate | DateTime? | 审核日期 |

### 异常

- `dates` / `datee` 为空 → `开始时间和结束时间不能为空`
- `state` / `recheck` 格式不正确 → `状态参数格式不正确`

## 2. 丝袜工艺单主表查询接口 `SGyMainQuery`

- **文件**：`/Technology/SGyMainQuery.aspx`
- **功能**：获取**丝袜**工艺单主表信息
- **请求方式**：GET/POST（表单参数）
- **核心条件**：参数均**模糊匹配**（非空才生效）

### 请求参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| bh | String | 编号 |
| hhtype | String | 产品类别（按货号类别名称匹配） |
| huohao | String | 货号 |
| spname | String | 品名 |
| dw | String | 单位 |
| dybanhao | String | 版号 |
| cxm | String | 程序名 |
| jix | String | 机型 |
| zs | String | 针数 |
| yajiao | String | 压脚 |
| nd | String | 牛顿 |
| hhywy | String | 业务员 |
| qd_dys | String | 前道打样师 |
| hd_dys | String | 后道打样师 |
| gylc | String | 工艺流程 |

### 响应结果（数组 `List<SGyMainQueryOutput>`）

| 字段 | 类型 | 说明 |
|------|------|------|
| bh | String | 编号 |
| hhtype | String | 货号类别 |
| huohao | String | 生产货号 |
| spname | String | 品名 |
| dybanhao | String | 版本号 |
| cxm | String | 程序名 |
| xjkz | Decimal? | 下机克重 |
| xjsl | Decimal? | 下机秒数 |
| pfkz | Decimal? | 缝拼克重 |
| cpkz | Decimal? | 成品克重 |
| zcl | Decimal? | 制成率 |
| jix | String | 机型 |
| zs | String | 针数 |
| yajiao | String | 压脚 |
| nd | String | 牛顿 |
| djcl | Decimal? | 理论产量 |
| hhywy | String | 业务员 |
| qd_dys | String | 前道打样师 |
| hd_dys | String | 后道打样师 |
| dw | String | 单位 |
| remark | String | 总备注 |
